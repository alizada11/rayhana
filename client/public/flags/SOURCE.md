# Country flag assets

The four SVGs are original downloads from [FlagCDN](https://flagcdn.com/), the flag service created by [Flagpedia](https://flagpedia.net). FlagCDN describes its assets as based on Wikimedia Commons vector files and makes them available for free embedding and programmatic download. The SVG download pattern is documented in the [United States flag API](https://flagpedia.net/the-united-states/download/api). Retrieved on 2026-11-10.

- `us.svg`: United States — https://flagcdn.com/us.svg
- `ca.svg`: Canada — https://flagcdn.com/ca.svg
- `au.svg`: Australia — https://flagcdn.com/au.svg
- `de.svg`: Germany — https://flagcdn.com/de.svg

These are unmodified source SVGs, not generated illustrations or emoji glyphs. `MarketFlag` serves them locally from `/flags/` to avoid dependence on external availability or the operating system's emoji fonts. Its explicit 30 × 20 image dimensions reserve a consistent display area; the site's flag styling controls fit. Images are decorative because an adjacent country label provides the accessible name. Emoji are used only as a supplementary prefix in native select options, where image markup is not supported.
